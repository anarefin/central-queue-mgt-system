Cross-cutting checks

Accessibility, dark mode and brand colour, responsive widths, concurrency, offline degradation, rate limits, the generic error codes, and security spot checks.

How to use this page

These checks apply to every app (Admin, Console, Kiosk, Display, Visitor) rather than one feature. Run each on at least Admin, Console and the Kiosk, and the Visitor page on a phone-sized window. Tools: a keyboard, a browser with DevTools (device toolbar, rendering emulation for *prefers-reduced-motion* and *prefers-color-scheme*), and curl.

Offline and degraded operation (UAT U7)

The LAN keeps working when the internet is lost (ADR-0001). Tokens keep issuing and serving; remote join and Web Push are shown as unavailable; there are no duplicate numbers. Detection is by a connectivity probe (qms.connectivity.probe-targets, failure-threshold 3, timeout 3 s; empty targets means *fail open*, always online).

TC-XCT-016

Internet loss degrades gracefully

unhappy
SRS
FR-QUE-202, UAT U7
Role
reception_operator, visitor
Steps
  1. Configure QMS_CONNECTIVITY_PROBE_TARGETS with a host you can block, and check-cron to run every few seconds.
  2. Block the host from the backend container (firewall or stop the target).
  3. Issue Tickets at Reception and the Kiosk; call and complete them; try remote join.
Expected

Walk-in issuing, calling, serving and displays continue. Remote join is refused internet_unreachable. Web Push shows unavailable. Token numbers are unique and sequential.

TC-XCT-025

Rate limits on public endpoints

unhappy
SRS
API-090, ticket 62/69
Role
developer
Steps
  1. Call GET /branding/theme 31 times in a minute from one address.
  2. Repeat with GET /labels/public and, with a device token, POST /kiosk/tickets beyond its limit.
  3. Request more than 5 visitor OTP codes for one email in an hour.
Expected

429 rate_limited with a Retry-After header. For branding and labels details carries limit, window_seconds and retry_after_seconds; OTP details list only limit and retry_after_seconds. JWT algorithm is pinned and none is rejected

unhappy
SRS

Role
