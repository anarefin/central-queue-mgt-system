Displays and voice announcements

The four layouts, columns and assignments, the stale banner, the notice board, announcements in each language, chime, quiet hours, queueing and the fallback when speech is unavailable.

A display is a dumb, resilient client

A paired display (/display/) subscribes to its Zone, renders what it is told and recovers by itself. It resumes its assigned Zone and layout after power loss with no login (its device credential is stored), and it can be revoked individually.

LayoutWhat it showsConfigurable
now_serving_table (default)table of serving Token / Counter / Service (or staff), plus a next strip per queuecolumns (token and counter mandatory; service, staff optional); next N (default 4, max 20); highlight seconds (default 10, max 300)
split_medianow-serving table beside a notice panellayout_config.split_percent 10 to 90 (default 60)
single_counterone huge Token for one Counter or roomlayout_config.counter_id (falls back to the Zone's first Counter)
summary_boardper-Service waiting counts and estimated wait for a lobbynone

Edit a display at Admin > Device pairing and fleet > the display > *Display config* (PUT /devices/{id}/display-config): layout, layout_config, language_cycle (subset of the Site's languages) and language_cycle_seconds (0 to 300, default 10), columns, next_n, highlight_seconds, and assignment = a whole zone, specific counters, or specific queues.

Behaviour to test: an update within 2 seconds of a call; a discreet stale indicator after 30 seconds without an update (*Update delayed - information may be out of date*), a full refetch every 20 seconds, and automatic reconnect. A newly called Token is highlighted for the highlight period.

Voice (per Zone)

On a call, the display's Zone plays a chime then an announcement in each configured language, in order, built from a template:

> *Attention please. Token A-004, Cash deposit, please proceed to Counter 3, Ground floor.*

  • Name announcements are a per-Service flag (default off, because they are inappropriate in medical settings) and the org flag announce_visitor_name; both must be on.
  • Audio is TTS in the browser, with a fallback to pre-recorded clip assembly if the browser has no speech or no voice for that language. The chime still plays. Prefix pronunciation is a per-language spoken form (Catalogue > token prefix).
  • Announcements queue, never overlap; beyond the Zone's maximum queue depth (1 to 20, default 5) only the most recent call per Counter is announced.
  • Quiet period (HH:mm start and end): audio is suppressed but the display still updates.
  • Re-announce (F3) repeats the announcement, up to the announce limit (default 3).
  • Token digits are always Western Arabic, in Bangla too.

Zone voice settings and spoken forms are API only in this build (PATCH /zones/{id}, PUT /token-prefixes/{prefix}/spoken-forms/{language}); there is no Admin form for them.
