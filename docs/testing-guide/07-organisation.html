Sites, zones and counters

The physical hierarchy: a Site owns hours, timezone and a numbering space; a Zone is a waiting area with displays and speakers; a Counter is a serving position.

Model

Organisation > Site > Zone > Counter (ADR-0002). A Site is the operational unit, a branch or a campus that may span several buildings; a building is a Zone attribute (building_label, floor_label). Journeys and Transfers are always within one Site.

Screen: Admin > Sites, zones and Counters (/admin/sites/), roles system_admin and org_admin (config:org_sites_zones). Nothing is ever deleted: a Site, Zone or Counter is deactivated, and deactivating a parent deactivates its active children, each audited with the reason *parent site deactivated* (or *zone*).

FieldRule
Site coderequired, at most 32 characters, [A-Za-z0-9_-]+, globally unique
Site timezonemust be a valid IANA zone, at most 64 characters
Site languagesdefault language must be installed and in the enabled list; no duplicates; enabled list must include the default
Zone chime (API only)chime_standard, chime_soft or chime_alert
Zone chime_volume0-100, default 80
Zone quiet periodHH:mm start and end, both or neither
Zone max_announce_queue_depth1-20, default 5
Second active Siteneeds the multi_site flag on (the first Site is never blocked)

The Admin form shows these errors beside the field before it sends anything (ticket 66); the server stays authoritative and re-checks.
